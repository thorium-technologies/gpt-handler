# 🧩 Modules

## Enhance Code Module

- **Purpose**:  
  Provides an API to enhance code snippets using GPT.

- **Key Files**:  
  - `enhance-code.controller.ts`: Handles HTTP requests.
  - `enhance-code.service.ts`: Contains the business logic for enhancing code.

- **Endpoints**:  
  - `POST /enhance-code`: Accepts a programming language and code snippet, returns the enhanced code.

---

## Programming Algorithm Module

- **Purpose**:  
  Provides an API to generate programming algorithms using GPT.

- **Key Files**:  
  - `programming-algorithm.controller.ts`: Handles HTTP requests.
  - `programming-algorithm.service.ts`: Contains the business logic for generating algorithms.

- **Endpoints**:  
  - `POST /programming-algorithm`: Accepts a programming language and algorithm description, returns the generated algorithm.
